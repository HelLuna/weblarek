# Интернет-магазин «Web-Larёk»

«Web-Larёk» — это интернет-магазин с товарами для веб-разработчиков, где пользователи могут просматривать товары, добавлять их в корзину и оформлять заказы. Сайт предоставляет удобный интерфейс с модальными окнами для просмотра деталей товаров, управления корзиной и выбора способа оплаты, обеспечивая полный цикл покупки с отправкой заказов на сервер.

## Архитектура приложения

Код приложения разделен на слои согласно парадигме MVP (Model-View-Presenter), которая обеспечивает четкое разделение ответственности между классами слоев Model и View. Каждый слой несет свой смысл и ответственность:

Model - слой данных, отвечает за хранение и изменение данных.  
View - слой представления, отвечает за отображение данных на странице.  
Presenter - презентер содержит основную логику приложения и отвечает за связь представления и данных.

Взаимодействие между классами обеспечивается использованием событийно-ориентированного подхода. Модели и Представления генерируют события при изменении данных или взаимодействии пользователя с приложением, а Презентер обрабатывает эти события используя методы как Моделей, так и Представлений.

### Базовый код

#### Класс Component

Является базовым классом для всех компонентов интерфейса.
Класс является дженериком и принимает в переменной `T` тип данных, которые могут быть переданы в метод `render` для отображения.

Конструктор:

- `constructor(container: HTMLElement)` - принимает ссылку на DOM элемент за отображение, которого он отвечает.

Поля класса:

- `container: HTMLElement` - поле для хранения корневого DOM элемента компонента.

Методы класса:

- `render(data?: Partial<T>): HTMLElement` - главный метод класса. Он принимает данные, которые необходимо отобразить в интерфейсе, записывает эти данные в поля класса и возвращает ссылку на DOM-элемент. Предполагается, что в классах, которые будут наследоваться от `Component` будут реализованы сеттеры для полей с данными, которые будут вызываться в момент вызова `render` и записывать данные в необходимые DOM элементы.
- `setImage(element: HTMLImageElement, src: string, alt?: string): void` - утилитарный метод для модификации DOM-элементов `<img>`

#### Класс Api

Содержит в себе базовую логику отправки запросов.

Конструктор:

- `constructor(baseUrl: string, options: RequestInit = {})` - В конструктор передается базовый адрес сервера и опциональный объект с заголовками запросов.

Поля класса:

- `baseUrl: string` - базовый адрес сервера
- `options: RequestInit` - объект с заголовками, которые будут использованы для запросов.

Методы:

- `get(uri: string): Promise<object>` - выполняет GET запрос на переданный в параметрах ендпоинт и возвращает промис с объектом, которым ответил сервер
- `post(uri: string, data: object, method: ApiPostMethods = 'POST'): Promise<object>` - принимает объект с данными, которые будут переданы в JSON в теле запроса, и отправляет эти данные на ендпоинт переданный как параметр при вызове метода. По умолчанию выполняется `POST` запрос, но метод запроса может быть переопределен заданием третьего параметра при вызове.
- `handleResponse(response: Response): Promise<object>` - защищенный метод проверяющий ответ сервера на корректность и возвращающий объект с данными полученный от сервера или отклоненный промис, в случае некорректных данных.

#### Класс EventEmitter

Брокер событий реализует паттерн "Наблюдатель", позволяющий отправлять события и подписываться на события, происходящие в системе. Класс используется для связи слоя данных и представления.

Конструктор класса не принимает параметров.

Поля класса:

- `_events: Map<string | RegExp, Set<Function>>)` - хранит коллекцию подписок на события. Ключи коллекции - названия событий или регулярное выражение, значения - коллекция функций обработчиков, которые будут вызваны при срабатывании события.

Методы класса:

- `on<T extends object>(event: EventName, callback: (data: T) => void): void` - подписка на событие, принимает название события и функцию обработчик.
- `emit<T extends object>(event: string, data?: T): void` - инициализация события. При вызове события в метод передается название события и объект с данными, который будет использован как аргумент для вызова обработчика.
- `trigger<T extends object>(event: string, context?: Partial<T>): (data: T) => void` - возвращает функцию, при вызове которой инициализируется требуемое в параметрах событие с передачей в него данных из второго параметра.

### Данные

#### Интерфейс IProduct

Представляет собой некоторый «**Товар**» в интернет-магазине:

```typescript
interface IProduct {
  id: string; // id товара
  description: string; // подробное описание товара
  image: string; // изображение товара
  title: string; // название товара
  category: string; // категория, к которой относится товар
  price: number | null; // цена товара
}
```

#### Интерфейс IBuyer

Описывает сущность «**Покупатель**» - пользователь интернет-магазина:

```typescript
interface IBuyer {
  payment: TPayment; // тип оплаты ("card" | "cash" | "")
  email: string; // электронная почта покупателя
  phone: string; // номер телефона покупателя
  address: string; // адрес покупателя
}
```

### Модели данных

#### Класс Catalog

Содержит массив всех товаров, которые можно приобрести в интернет-магазине, а также выбранный товар для подробного отображения.

Конструктор:

- `constructor(products: IProduct[] = [], selectedProduct: IProduct | null = null)` - в конструктор передаются перечень существующих товаров и текущий выбранный товар.

Поля класса:

- `products: IProduct[]` - массив товаров.
- `selectedProduct: IProduct | null` - выбранная карточка товара.

Методы класса:

- `setProducts(products: IProduct[]): void` - сохраняет массив товаров, полученный в параметрах метода, в переменную `products`.
- `getProducts(): IProduct[]` - получает копию массива товаров `products`.
- `getProductById(id: string): IProduct | undefined` - получает товар по его id. Если товар не найден, то возвращает `undefined`.
- `setSelectedProduct(product: IProduct): void` - сохраняет товар для подробного отображения в `selectedProduct`.
- `getSelectedProduct(): IProduct | null` - получает товар для подробного отображения.

#### Класс Basket

Хранит массив товаров, которые выбрал пользователь для покупки.

Конструктор:

- `constructor(items: IProduct[] = [])` - в конструктор передаётся массив выбранных пользователем товаров.

Поля класса:

- `items: IProduct[]` - массив выбранных товаров.

Методы класса:

- `getItems(): IProduct[]` - получает массив товаров, которые находятся в корзине.
- `addItem(item: IProduct): void` - добавляет товар, который был получен в параметре, в массив корзины.
- `removeItem(item: IProduct): void` - удаляет товар, полученный в параметре, из массива корзины.
- `clear(): void` - удаляет все товары из корзины.
- `getTotalPrice(): number` - получает общую стоимость всех товаров в корзине.
- `getAmount(): number` - получает количество товаров в корзине.
- `hasItem(id: string): boolean` - проверяет наличие товара в корзине по его id, полученного в параметр метода.

#### Класс Buyer

Содержит данные о покупателе, которые тот должен указать при оформлении заказа.

Конструктор:

- `constructor(payment: TPayment = "", email: string = "", phone: string = "", address: string = "")` - в конструктор передаются данные покупателя: выбранный тип оплаты, email, номер телефона и адрес.

Поля класса:

- `payment: TPayment | ""` - тип оплаты. `TPayment` может принимать одно из следующих значений: `"card"`, `"cash"`.
- `email: string` - электронная почта.
- `phone: string` - номер телефона.
- `address: string` - адрес.

Методы класса:

- `setInfo(newData: Partial<IBuyer>): void` - сохраняет переданные данные в модель.
- `getInfo(): IBuyer` - возвращает все данные покупателя в виде объекта.
- `clear(): void` - очищает данные покупателя.
- `validateInfo(): TBuyerError` - производит валидацию данных. Возвращает объект типа `TBuyerError`, в котором могут присутствовать поля, соответствующие полям класса. Значения этих полей - текст ошибки. Если объект пуст, то ошибок не обнаружено.

### Слой коммуникации

#### Класс Communicator

Представляет собой «коммуникатор», который соединяет приложение и сервер. Позволяет выполнять запрос с помощью метода `get` класса `Api` и получить с сервера объект с массивом товаров, а также метод `post`, чтобы отправлять на сервер данные о покупателе и выбранных товарах.

Конструктор:

- `constructor(api: IApi)` - принимает объект, соответствующий интерфейсу `IApi`.

Поля класса:

- `api: IApi` - ссылка на экземпляр класса `Api`, используемый для выполнения запросов к серверу.

Методы класса:

- `getProductList(): Promise<TProductListResponse>` - выполняет GET-запрос на эндпоинт `/product/`. Возвращает объект с массивом товаров и их количеством от сервера.
- `postOrderData(orderData: TOrderRequest): Promise<TOrderResponse>` - отправляет POST-запрос на эндпоинт `/order/` с данными о покупателе, общей сумме заказа и id товаров из корзины покупателя. Возвращает с сервера объект с id созданного заказа и его суммой.

### Слой представления (View)

#### Класс Header

Компонент шапки страницы. Отвечает за отображение кнопки корзины и счётчика товаров, а также за обработку клика по кнопке, генерируя событие `basket:open`.

Конструктор:

- `constructor(protected events: IEvents, container: HTMLElement)` - принимает брокер событий и ссылку на DOM-элемент, который компонент отображает.

Поля класса:

- `basketButton: HTMLButtonElement` - ссылка на кнопку корзины.
- `counterElement: HTMLElement` - ссылка на счётчик товаров в корзине.

Методы класса:

- `set counter(value: number)` - устанавливает количество товаров в корзине, полученное в параметрах метода, в текстовое содержимое HTML-элемента `counterElement`.

Данные для передачи в **Component**:

```typescript
interface IHeader {
  counter: number; // количество товаров в корзине
}
```

#### Класс Gallery

Компонент галереи со всеми товарами. Отображает список карточек через свойство `catalog`. При помощи сеттера обновляет DOM - очищает и рендерит новый набор.

Конструктор:

- `constructor(container: HTMLElement)` - принимает ссылку на DOM-элемент, отображающий галерею.

Поля класса:

- `catalogElement: HTMLElement` - ссылка на каталог, внутри которого отображаются карточки товаров.

Методы класса:

- `set catalog(items: HTMLElement[])` - очищает содержимое каталога и устанавливает новый массив с карточками товаров в содержимое `catalogElement`.

Данные для передачи в **Component**:

```typescript
interface IGallery {
  catalog: HTMLElement[]; // массив из карточек товаров
}
```

#### Класс Modal

Компонент модального окна. Отвечает за отображение модального окна с кнопкой закрытия. Уведомляет о клике по кнопке или вне модального окна, генерируя событие `modal:close`.

Конструктор:

- `constructor(protected events: IEvents, container: HTMLElement)` - принимает брокер событий и ссылку на DOM-элемент, представляющий собой модальное окно.

Поля класса:

- `closeButton: HTMLButtonElement` - ссылка на кнопку закрытия модального окна.
- `contentElement: HTMLElement` - ссылка на элемент, в котором отображается контент.

Методы класса:

- `set content(element: HTMLElement)` - очищает содержимое модального окна и устанавливает новый контент для отображения в `contentElement`.

Данные для передачи в **Component**:

```typescript
interface IModal {
  content: HTMLElement; // HTML-элемент, в котором будет отрисован контент
}
```

#### Класс Card

Родительский абстрактный компонент карточки товара. Отвечает за отображение общих для всех карточек данных - наименования и цены. Самостоятельно не используется, от него наследуются `CardCatalog`, `CardPreview` и `CardBasket`. Класс является дженериком и принимает в переменной `T` тип с дополнительными данными класса-наследника. В `Component` передаётся объединение `TCard & T`. Дополнительно задаёт необходимый интерфейс `ICardActions` для получаемых в конструкторе обработчиков событий.

Конструктор:

- `constructor(container: HTMLElement)` - принимает ссылку на DOM-элемент, являющийся карточкой товара.

Поля класса:

- `titleElement: HTMLElement` - ссылка на элемент, содержащий наименование товара.
- `priceElement: HTMLElement` - ссылка на элемент с ценой товара.

Методы класса:

- `set title(value: string)` - устанавливает наименование товара, полученное в параметрах, в текстовое содержимое `titleElement`.
- `set price(value: number | null)` - устанавливает указанную цену товара в `priceElement`. Если значение цены `null`, то отображает значение **"Бесценно"**.

Данные для передачи в **Component**:

```typescript
type TCard = Pick<IProduct, "title" | "price">; // наименование и цена товара из интерфейса IProduct
```

#### Класс CardCatalog

Компонент карточки товара в каталоге. Наследуется от `Card` и дополняет её категорией и изображением товара. Уведомляет о клике по карточке вызовом обработчика, переданного в конструкторе.

Конструктор:

- `constructor(container: HTMLElement, actions?: ICardActions)` - принимает ссылку на элемент, который соответствует карточке товара в каталоге (клон шаблона `card-catalog`), а также необязательный объект с обработчиками событий.

Поля класса:

- `categoryElement: HTMLElement` - ссылка на элемент, в котором отображается категория товара.
- `imageElement: HTMLImageElement` - ссылка на элемент с изображением товара.

Методы класса:

- `set category(value: string)` - устанавливает товару указанную категорию в текстовое содержимое `categoryElement` и переключает модификатор фона согласно объекту `categoryMap`.
- `set image(value: string)` - устанавливает картинку товара в `imageElement` при помощи метода `setImage` из класса `Component`.

Данные для передачи в **Card** и объединения с **Component**:

```typescript
type TCardCatalog = Pick<IProduct, "category" | "image">; // категория и изображения товара из интерфейса IProduct
```

#### Класс CardPreview

Компонент карточки товара с полной информацией. Наследуется от `Card` и дополняет её изображением, категорией и описанием товара. Уведомляет о клике по кнопке покупки вызовом обработчика.

Конструктор:

- `constructor(container: HTMLElement, actions?: ICardActions)` - принимает ссылку на элемент, который соответствует карточке с полной информацией о товаре (клон шаблона `card-preview`), а также необязательный объект с обработчиками событий.

Поля класса:

- `buyButton: HTMLButtonElement` - ссылка на кнопку покупки товара.
- `imageElement: HTMLImageElement` - ссылка на элемент с изображением товара.
- `categoryElement: HTMLElement` - ссылка на элемент с категорией товара.
- `descriptionElement: HTMLElement` - ссылка на элемент с описанием товара.

Методы класса:

- `set image(value: string)` - устанавливает картинку товара в `imageElement` при помощи метода `setImage` из класса `Component`.
- `set category(value: string)` - устанавливает товару указанную категорию в текстовое содержимое `categoryElement` и переключает модификатор фона согласно объекту `categoryMap`.
- `set description(value: string)` - устанавливает описание товара в текстовое содержимое `descriptionElement`.
- `set btnLabel(value: TBtnLabel)` - устанавливает текст внутрь кнопки `buyButton`. `value` может принимать одно из следующих значений, указанных в `TBtnLabel`: "Купить", "Удалить из корзины", "Недоступно".
- `set isBtnDisabled(value: boolean)` - устанавливает атрибут `disabled` у элемента `buyButton` в зависимости от переданного значения.

Данные для передачи в **Card** и объединения с **Component**:

```typescript
type TCardPreview = Pick<IProduct, "image" | "category" | "description"> & {
  btnLabel: TBtnLabel; // текст для кнопки покупки
  isBtnDisabled: boolean; // состояние атрибута 'disabled' у кнопки покупки
};
```

#### Класс CardBasket

Компонент карточки товара в корзине. Наследуется от `Card`, дополняя её индексом товара. Уведомляет о клике по кнопке удаления из корзины вызовом обработчика.

Конструктор:

- `constructor(container: HTMLElement, actions?: ICardActions)` - принимает ссылку на DOM-элемент, соответствующий карточке товара в корзине (клон шаблона `card-basket`), а также необязательный объект с обработчиками событий.

Поля класса:

- `deleteButton: HTMLButtonElement` - ссылка на кнопку удаления товара из корзины.
- `indexElement: HTMLElement` - ссылка на элемент с номером товара в корзине.

Методы класса:

- `set index(value: number)` - устанавливает переданный номер товара в корзине в текстовое содержимое элемента `indexElement`.

Данные для передачи в **Card** и объединения с **Component**:

```typescript
type TCardBasket = {
  index: number; // номер товара в корзине
};
```

#### Класс Basket

Компонент корзины покупателя. Отображает список выбранных товаров и их общую стоимость. При помощи брокера событий генерирует событие клика по кнопке оформления покупки `order:open`.

Конструктор:

- `constructor(protected events: IEvents, container: HTMLElement)` - принимает брокер событий и ссылку на DOM-элемент, который соответствует корзине покупок.

Поля класса:

- `orderButton: HTMLButtonElement` - ссылка на кнопку оформления заказа.
- `listElement: HTMLElement` - ссылка на элемент, в котором отображается список выбранных товаров.
- `totalElement: HTMLElement` - ссылка на элемент с общей суммой товаров в корзине.

Методы класса:

- `set list(items: HTMLElement[])` - заменяет содержимое корзины и устанавливает новый массив с выбранными товарами в содержимое `listElement`.
- `set total(value: number)` - устанавливает переданное значение в качестве общей суммы товаров в элементе `totalElement`.
- `set isBtnDisabled(value: boolean)` - устанавливает значение атрибута `disabled` у элемента `orderButton` в зависимости от переданного значения.

Данные для передачи в **Component**:

```typescript
interface IBasket {
  list: HTMLElement[]; // список элементов корзины
  total: number; // общая сумма товаров в корзине
  isBtnDisabled: boolean; // состояние атрибута 'disabled' у кнопки
}
```

#### Класс OrderForm

Родительский абстрактный компонент формы оформления заказа. Отвечает за отображение общих элементов - текста ошибки. Самостоятельно не используется, от него наследуются `OrderPaymentForm` и `OrderContactsForm`. Класс является дженериком и принимает в переменной `T` тип с дополнительными данными класса-наследника. В `Component` передаётся объединение `IOrderForm & T`.

Конструктор:

- `constructor(container: HTMLFormElement)` - принимает ссылку на DOM-элемент, отвечающий за отображение формы оформления заказа.

Поля класса:

- `errorElement: HTMLElement` - ссылка на элемент, в котором отображается текст ошибки при заполнении форм.

Методы класса:

- `set error(value: string)` - устанавливает текст соответствующей ошибки в текстовое содержимое `errorElement`.

Данные для передачи в **Component**:

```typescript
interface IOrderForm {
  error: string; // текст ошибки
}
```

#### Класс OrderPaymentForm

Компонент формы оформления заказа с выбором способа оплаты и вводом адреса. Наследуется от `OrderForm`. Уведомляет об изменениях оплаты и поля адреса вызовом переданных обработчиков. Также генерирует событие об отправке текущей формы `order:next`. Дополнительно задаёт интерфейс `IOrderPaymentActions` для получаемых в конструкторе обработчиков событий.

Конструктор:

- `constructor(protected events: IEvents, container: HTMLFormElement, actions?: IOrderPaymentActions)` - принимает брокер событий, ссылку на DOM-элемент, соответствующий форме заказа с типом оплаты и адресом (клон шаблона `order`) и необязательный объект с обработчиками событий.

Поля класса:

- `onlinePaymentButton: HTMLButtonElement` - ссылка на кнопку выбора оплаты "Онлайн".
- `cashPaymentButton: HTMLButtonElement` - ссылка на кнопку выбора оплаты "При получении".
- `addressInput: HTMLInputElement` - ссылка на поле ввода адреса покупателя.
- `nextButton: HTMLButtonElement` - ссылка на кнопку перехода к следующему этапу оформления заказа.

Методы класса:

- `set payment(value: TPayment | "")` - устанавливает выбранный способ оплаты в зависимости от переданного значения.
- `set address(value: string)` - устанавливает значение адреса в поле `addressInput`. Необходимо, например, для очистки поля после оформления заказа.
- `set isBtnDisabled(value: boolean)` - устанавливает значение атрибута `disabled` у элемента `nextButton` в зависимости от переданного значения.

Данные для передачи в **OrderForm** и объединения с **Component**:

```typescript
type TOrderPaymentForm = Pick<IBuyer, "payment" | "address"> & {
  isBtnDisabled: boolean; // состояние 'disabled' у кнопки продолжения оформления
};
```

#### События, относящиеся к Представлениям (views):

**Генерируются классом через брокер событий**:
| Событие | Класс | Когда генерируется | Действие подписчика |
| --- | --- | --- | --- |
| `basket:open` | `Header` | Клик по кнопке корзины в шапке | Собирает содержимое корзины и открывает модальное окно, добавляя модификатор `modal_active` |
| `modal:close` | `Modal` | Клик по крестику или вне окна | Снимает модификатор `modal_active` |
| `order:open` | `Basket` | Клик по кнопке **"Оформить"** | Открывает первую форму оформления |
| `order:next` | `OrderPaymentForm` | Отправка формы кнопкой **"Далее"** | Показывает вторую форму оформления |
| `order:pay` | `OrderContactsForm` | Отправка формы кнопкой **"Оплатить"** | Отправляет заказ на сервер, показывает `OrderSuccess`, очищает корзину, данные покупателя и обе формы |
| `order:complete` | `OrderSuccess` | Клик по кнопке **"За новыми покупками!"** | Закрывает модальное окно |

**Генерируются презентером из обработчика, переданного в конструктор**:
| Событие | Обработчик | Когда генерируется | Действие подписчика |
| --- | --- | --- | --- |
| `card:select` | `onClick` в `CardCatalog` | Клик по карточке в каталоге | Создаёт `CardPreview` с помощью функции `renderPreviewCard` и открывает модальное окно с товаром |
| `card:buy` | `onClick` в `CardPreview` | Клик по кнопке **"Купить"** | Добавляет товар в корзину, перерисовывает счётчик и выбранный товар |
| `card:delete` | `onClick` в `CardPreview` | Клик по кнопке **"Удалить из корзины"** | Удаляет товар из корзины, перерисовывает счётчик и выбранный товар |
| `basket:delete` | `onClick` в `CardBasket` | Клик по кнопке удаления у товара в корзине | Удаляет товар, обновляет счётчик и перерисовывает корзину |
| `order:payment-change` | `onPaymentChange` в `OrderPaymentForm` | Клик по кнопке **"Онлайн"** или **"При получении"** | Сохраняет способ оплаты и перерисовывает форму с подсветкой кнопки и текстом ошибки (функция `renderOrderPaymentForm`) |
| `order:address-change` | `onAddressChange` в `OrderPaymentForm` | Ввод в поле адреса | Сохраняет адрес и перерисовывает форму |
| `order:email-change` | `onEmailChange` в `OrderContactsForm` | Ввод в поле email | Сохраняет email и перерисовывает форму |
| `order:phone-change` | `onPhoneChange` в `OrderContactsForm` | Ввод в поле телефона | Сохраняет телефон и перерисовывает форму |

**Дополнительные события**:

- `catalog:changed` - срабатывает при изменении каталога товаров. На каждый товар создаёт экземпляр класса `CardCatalog` и отображает все карточки в каталоге.
